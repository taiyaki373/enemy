# ENEMY — 魔獣の防衛戦 FPS

モンスターを操作して、圧倒的に強いAIの冒険者5人と戦う一人称の3Dブラウザゲームです。

`index.html` をWebGL対応ブラウザで開くと遊べます。Three.jsを同梱しているため、実行時のネット接続や依存パッケージのインストールは不要です。サーバーで起動する場合は `python3 -m http.server 8000 --bind 0.0.0.0` を使います。

- WASD / 矢印キー：視点に対して前後・左右に移動
- マウス：画面クリック後に視点操作（Escで解除）
- 左クリック：前方へ突進（クールダウン3秒）。基本威力150（`game.js` の `dashStats.damage`）、通常威力の範囲120〜170。職業補正後は剣士120・弓使い150・魔術師170・僧侶150。命中ごとに5%で1.4倍のクリティカル、実際の与ダメージの7%を回復（最大HPまで）。最初のクリックで視点操作も開始
- 右クリック：眷属5体を召喚（クールダウン2秒）
- Q：照準地点への遠隔範囲攻撃（クールダウン5秒、半径は旧版の3倍、予告後に爆発。閃光・衝撃波・火花・煙の演出と障害物の倒壊）

ポインターロック非対応環境では画面ドラッグで視点操作できます。タッチ操作では左スティックで移動、画面ドラッグで視点、ボタンで技を使います。

ステージは80×64の広さ（初期版の約5.3倍の面積）。17個の石壁・石柱が移動、突進、射撃を遮り、AIは障害物を迂回します。操作モンスターの遠隔範囲攻撃に触れた障害物は倒壊し、瓦礫は移動・射線を遮りません。「再挑戦」で障害物も復元します。

- 剣士：HP2200。素早く接近し、重い近接範囲攻撃。突進以外の被ダメージ30%軽減
- 弓使い：HP1560。距離を取りながら高速の矢を三連射
- 魔術師：HP1440。予告付きの大きな範囲魔法で魔獣と眷属を攻撃
- 僧侶：HP1800。光線攻撃と、周辺の仲間の回復・防護
- 重装タンク：HP3600。低速で接近し、予告付きの盾殴り（威力110）。突進を含む全被ダメージを50%軽減。半径240以内かつ射線が通る仲間の被ダメージを25%軽減（僧侶の防護と重複）

僧侶の防護中は突進を含むダメージが軽減され、吸収回復も軽減後の実ダメージから算出します。

冒険者のHPは前版の2倍、攻撃力は約1.5倍です。敵は範囲攻撃から逃れようとします。立ち止まったままの正面戦闘は非常に厳しい難易度です。障害物で射線を切り、眷属に敵を引きつけさせながら戦えます。

眷属は1回5体、各HP320、活動時間30秒。自動で敵を追い、突進と遠隔範囲攻撃を使います。眷属には召喚能力はありません。

画面上部に冒険者5人の現在HP・最大HPとHPバーを表示します。

冒険者を全員倒せば勝利、魔獣のHPが0になると敗北です。「再挑戦」で戦闘をリセットできます。

3Dモデルはコードで組み立てた試作モデルです。Three.js r160のライセンスは `vendor/THREE-LICENSE.txt` に同梱しています。

戦闘・倒壊の回帰テスト：`node --test tests/combat.test.cjs`
